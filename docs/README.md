# Photo-Tools

同一应用里的两款图片工具：左侧共用添加 / 列表，header 切换工具，右侧随工具变化。本期 **不引入 React Router**，用 `useState` 切换。默认打开修图对比。

## 工具规格

每个工具一份文档：

| 工具 | 状态 | 规格 |
|------|------|------|
| [修图对比](./COMPARE.md) | 已实现 | 勾选两张图，分界线 / 闪烁对比，可裁剪、导出 GIF |
| [拼图](./COLLAGE.md) | 待实现 | 固定比例画布，按张数均分格子，cover 裁切后导出 |

---

## 目标

- header 可在「修图对比 / 拼图」之间切换，当前项高亮
- 左右布局保持现在这样：**左侧添加 / 选择图片，右侧随工具变化**
- 图片列表共用一份；**勾选规则随工具变化**（对比最多 2 张，拼图不限制张数）

---

## 界面壳

与现有 `App` 一致，只在 header 增加工具切换：

| 区域 | 说明 |
|------|------|
| **Header** | 产品名 Photo-Tools + 工具切换（修图对比 / 拼图），默认修图对比 |
| **左侧栏** | 添加图片 + 待选列表（两套工具共用） |
| **右侧主区** | `tool === "compare"` 为对比预览 / 裁剪；`tool === "collage"` 为拼图画布 |

```
tool: "compare" | "collage"   // useState，默认 "compare"
```

切换只换右侧组件和勾选行为，不换 URL，不整页刷新。

## 共享状态与勾选规则

两套工具共用：

- `items: ImageItem[]`（添加、粘贴、删除都写这份列表）
- `selectedIds: string[]`（勾选顺序 = 对比的 A/B 顺序，也是拼图从左到右、从上到下的格子顺序）

不共用的是各工具自己的 UI 状态（对比的模式 / 裁剪中；拼图的比例、分辨率、行列布局）。

### 修图对比

详见 [COMPARE.md](./COMPARE.md)。列表内：

- 最多勾选 **2** 张
- 已满两张再点第三张：去掉最早选中的，留下最新两张

### 拼图

详见 [COLLAGE.md](./COLLAGE.md)。列表内：

- **不限制** 勾选数量（1 张也能拼；0 张则右侧提示）
- 可自由取消任意一张
- 张数变化后，右侧按拼图规格重算合法布局

### 在两种工具间切换时

切换时 **丢掉当前选中态**，按目标工具重新设定，不沿用上一工具勾了哪些：

| 切到 | `selectedIds` |
|------|----------------|
| 修图对比 | **全部取消**，`[]` |
| 拼图 | **全选**当前列表，顺序与 `items` 一致 |

`items` 本身不动。切到拼图时若列表为空，全选结果仍是 `[]`，右侧按未选图处理。

左侧列表在两种工具下都展示全部已添加图片；只是「再点一张会怎样」不同。列表文案随工具切换，例如对比写「勾选两张进行对比」，拼图写「勾选要拼入的图片」。

## Feature S01 — Header 工具切换

**目标**：用户能在修图对比和拼图之间切换。

### 功能点

- header 内两个按钮（或等价 segmented control）：修图对比、拼图
- 默认选中修图对比
- 当前工具高亮；点击切换 `tool` state
- 右侧立即换成对应工具；左侧列表还在，不必重新添加图片
- 切换时丢掉选中态：切到对比则全部取消；切到拼图则全选列表

### 验收标准

- [ ] 打开应用默认是修图对比，现有能力可用
- [ ] 点「拼图」后右侧变为拼图预览区，左侧图片仍在，且列表全部勾选
- [ ] 再切回对比，所有勾选被清空，需重新勾两张才能对比
- [ ] 不引入 React Router，URL 不参与切换

---

## Feature S02 — 按工具切换勾选上限

**目标**：同一套列表，对比锁 2 张，拼图不锁张数。

### 验收标准

- [ ] 对比模式下无法稳定保持 3 张及以上选中
- [ ] 拼图模式下可选 3 张、4 张以及更多，预览格子数跟随选中数
- [ ] 从对比切到拼图：不论刚才勾了 0/1/2 张，结果都是列表全选
- [ ] 从拼图切到对比：不论刚才勾了多少张，结果都是全部取消
